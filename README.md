# cafe-landing

동네 카페 "온기 커피"를 소개하는 간단한 정적 랜딩 페이지입니다. 빌드 과정이나 외부 라이브러리 없이 HTML과 CSS만으로 만들었습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 대표 메뉴, 카페 소개, 오시는 길) |
| `style.css` | 스타일 (따뜻한 베이지/브라운 톤, 모바일 대응) |
| `README.md` | 이 문서 |

## 사용 방법

`index.html`을 브라우저로 열면 바로 확인할 수 있습니다.

## 수정 안내

- 카페 이름, 주소, 전화번호, 메뉴, 가격은 임시 값입니다. `index.html`에서 실제 정보로 바꿔 주세요.
- 색상은 `style.css` 맨 위의 `:root` 변수에서 바꿀 수 있습니다.
